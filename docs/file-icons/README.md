# File icons for solutions and projects

Icons for the file manager (the Linux file types in [Solution Explorer](../solution-explorer.md#opening-a-solution-or-project-file)), the same the Solution Explorer shows: the solution, and C#, Visual Basic and F# projects.

They are [codicons](https://github.com/microsoft/vscode-codicons) (`project` and `file-code`) by Microsoft, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), coloured as the Solution Explorer colours them.
